# Business Lens

Use this lens to explain why a mission matters beyond code.

## User value
- Does this reduce friction, reduce failed transactions, improve clarity, or increase trust?

## Operator value
- Does this improve control, governance, risk management, supportability, or observability?

## Product value
- Does this unlock a new workflow, better retention, safer growth, or protocol revenue potential?

## Market credibility
- Does this make the product look like a serious financial system instead of a demo?
- Examples: role separation, risk checks, structured deployment, indexable events, failure isolation.

## Decision framing
Use one sentence in this shape when helpful:
- "This task matters because it converts [fragile/manual/toy behavior] into [operable/trustworthy/scalable product behavior]."
